# Spotify Web Player UI Clone 🎵

A responsive UI clone of the Spotify Web Player built using **HTML and CSS**.

## ✨ Features
- Sidebar navigation (Home, Search, Library)
- Sticky top navigation
- Card-based content layout
- Fully styled music player (album, controls, volume)
- Spotify-like dark theme

## 🛠 Tech Stack
- HTML5
- CSS3 (Flexbox)
- Font Awesome

## 🎯 What I learned
- Advanced Flexbox layouts
- Sticky positioning
- UI polish and visual hierarchy
- Real-world icon and asset handling
